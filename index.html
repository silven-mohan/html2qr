HTMLQR

Put a whole webpage inside a QR code.

Paste a small page of HTML and get one QR code that carries every byte of it, with no server storing the page. Scan it and the page rebuilds on the phone itself.

How should the page travel inside the code?

Compress, then decode on a page

HTML›GZIP›Base64›HTMLQR1/2:

The HTML is compressed and stored in the QR as a link back to this same app. Scanning opens the app, which unpacks the page and runs it. The data never leaves the QR.

Convert to a data URL

HTML›minify›data: URL

The HTML is written straight into a data:text/html URL and encoded as the QR. Nothing to host, but the page has to fit uncompressed.
